Data Sources & Methodology

All sources are publicly available. Where live API access was unavailable, series are calibrated from the published figures cited below.

Methodology

· Frequency matching: annual data used throughout; where monthly M2 available, annual averages computed
· Broad money defined as M2 or M3 depending on national definition; IMF IFS classification followed
· Stationarity: ADF test confirms both bm_growth (ADF=−9.73, p<0.0001) and CPI (ADF=−9.42, p<0.0001) are I(0)
· Lag analysis: Pearson cross-correlations at lags 0–4 years; best lag selected by |r| maximisation
· Outlier treatment: values capped at 300% for scatter plot legibility; full values used in correlation
· Pooled regression uses country-year panel; country fixed effects not applied (see summary for discussion)
